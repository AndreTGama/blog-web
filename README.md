## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the home page in `app/[locale]/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Languages

Portuguese is the default language and uses unprefixed URLs; English pages use the `/en` prefix. Update interface copy in `messages/pt.json` and `messages/en.json`.

Articles are separate posts authored manually in each language. Create the second version from the post dashboard's translation action; the versions share a translation group and each has its own slug and content. Apply the API migration with `php artisan migrate` before deploying the locale fields.
